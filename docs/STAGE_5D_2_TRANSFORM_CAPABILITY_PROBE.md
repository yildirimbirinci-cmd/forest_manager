# Stage 5D.2 - Forest Transform Capability Probe

Purpose: identify the actual Forest Pack 9.4 scale/rotation/translation MaxScript properties available on the live Forest object before any transform values are changed.

This stage is read-only. It does not modify density, probabilities, scale, rotation, translation, geometry, or scene objects.

Command: GET_TRANSFORM_CAPABILITIES

CLI: python -m forest_manager.app.transform_probe_stage5d2
